# 📄 PDF RAG Chat

Chat with your PDF documents. Upload a PDF, let the app split it into chunks and store vector embeddings, then ask questions in natural language. The most relevant chunks are retrieved by semantic search and passed to an LLM, which answers using only your document's content (Retrieval-Augmented Generation).

> Forked from [piyushgarg-dev/pdf-rag-code](https://github.com/piyushgarg-dev/pdf-rag-code).

---

## ✨ Features

- Upload PDF files and index them automatically
- Semantic search over document chunks using vector embeddings
- Context-aware answers generated by an LLM from retrieved content
- Separate `client` (UI) and `server` (API) applications
- `docker-compose.yml` for running supporting services locally

---

## 🧠 How It Works

```
PDF upload
   │
   ▼
Extract text ─► split into chunks ─► create embeddings ─► store in vector DB
                                                              │
User question ─► embed question ─► similarity search ◄────────┘
                                         │
                                         ▼
                        LLM prompt = question + top chunks
                                         │
                                         ▼
                                  Answer in chat UI
```

1. **Indexing:** the uploaded PDF is parsed, chunked and embedded, and the vectors are stored in a vector database.
2. **Retrieval:** the question is embedded with the same model and the nearest chunks are fetched.
3. **Generation:** the chunks are sent to the LLM as context to produce a grounded answer.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/srmarohit/pdf-rag-code.git
cd pdf-rag-code
```

### 2. Start infrastructure services

```bash
docker compose up -d
```

This starts the services defined in `docker-compose.yml` (vector database and any supporting services).

### 3. Run the server

```bash
cd server
npm install
```

Create `server/.env`:

```env
OPENAI_API_KEY=your_openai_api_key
```

Add any other variables your `server` code reads (for example vector DB or Redis URLs), then:

```bash
npm run dev
```

### 4. Run the client

```bash
cd ../client
npm install
npm run dev
```

Open the URL printed in the terminal (typically `http://localhost:3000` or `http://localhost:5173`).

## 💬 Usage

1. Open the client in your browser.
2. Upload a PDF and wait until indexing finishes.
3. Ask questions such as:
   - "Summarize this document in five bullet points."
   - "What does the document say about pricing?"
   - "List all deadlines mentioned."
4. Read the answer generated from the retrieved sections.

## 🛠️ Troubleshooting

| Problem | Fix |
| ------- | --- |
| Environment variables are `undefined` | Load dotenv before other imports (`import "dotenv/config"` as the first line) or run with `--env-file=.env`. Restart after editing `.env`. |
| Cannot connect to the vector database | Confirm containers are running with `docker compose ps` and that ports match your `.env` values. |
| Answers are empty or irrelevant | Make sure the PDF finished indexing and that the same embedding model is used for indexing and querying. |
| Scanned PDFs return no text | Text extraction needs selectable text. Use OCR for image-only PDFs. |
